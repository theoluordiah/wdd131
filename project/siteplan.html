Site Plan

WDD 131 Final Project - Oluchukwu Ordiah

Site Name

Lagos Tech Connect

I picked this name because the site helps people in Lagos connect with the tech scene here, like communities, meetups, and places to work from.

Domain idea: lagostechconnect.ng

Site Purpose

The site is a guide to tech communities in Lagos for developers, designers, and other creatives. It will list communities, upcoming events, coworking spaces, and some useful resources. Visitors can filter the communities and use a form to suggest a community or event that should be added.

Scenarios

  • I'm new to programming. Are there any communities in Lagos for beginners?
  • What tech events are happening in Lagos this month?
  • Where can I find a coworking space in Yaba?
